# ⚡ Proposta Rápida

Gerador de propostas comerciais profissionais criado para freelancers, designers, social media, desenvolvedores e pequenas agências.

O objetivo do projeto é permitir que qualquer pessoa crie propostas bonitas e profissionais em poucos minutos, sem complicação.

---

## 🚀 Funcionalidades

### ✅ Versão Gratuita
- Geração de propostas em tempo real
- Exportação em PDF
- Layout profissional
- Sem cadastro

### 🔒 Versão PRO
- PDF sem marca d’água
- Experiência limpa e profissional
- Acesso exclusivo via link

---

## 🧱 Stack

- Next.js
- React
- Tailwind CSS
- TypeScript

---

## 📦 Estrutura do Projeto

```bash
/app
  /page.tsx             → Landing page
  /create/page.tsx      → Gerador gratuito
  /pro/page.tsx         → Página de vendas
  /create-pro/page.tsx  → Gerador PRO
  /thanks/page.tsx      → Página de agradecimento

/components
  ProposalPreview.tsx

/styles
  globals.css
```

---

## 🎯 Objetivo

Criar uma ferramenta simples, rápida e acessível para ajudar profissionais a enviarem propostas com aparência mais profissional e aumentarem sua percepção de valor.

---

## 💡 Filosofia do projeto

O projeto foi desenvolvido seguindo uma regra simples:

> Se não for essencial, não entra.

Foco total em:
- velocidade
- usabilidade
- simplicidade
- percepção de valor

---

## 🖨️ Exportação em PDF

A geração de PDF utiliza `window.print()` para manter o layout fiel ao preview da proposta.
